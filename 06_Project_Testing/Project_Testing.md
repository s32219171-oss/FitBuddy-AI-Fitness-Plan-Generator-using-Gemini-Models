# FitBuddy – AI Fitness Plan Generator using Gemini Models

## Phase 6 – Project Testing

### 1. Testing Objective

The objective of testing is to verify that the FitBuddy application
accepts user fitness details, processes the input using the Gemini model,
and generates the expected fitness plan.

### 2. Test Cases

| Test Case | Input | Expected Result |
|---|---|---|
| User details input | Valid fitness details | Details should be accepted |
| Fitness goal | Weight loss | Suitable plan should be generated |
| Fitness goal | Muscle building | Suitable workout suggestions should be generated |
| Activity level | Beginner | Beginner-level suggestions should be provided |
| Empty input | No fitness details | User should be asked to provide required details |
| AI processing | Valid prompt | Gemini should generate a response |
| Output display | Generated fitness plan | Plan should be displayed clearly |

### 3. Testing Process

1. Enter the required fitness details.
2. Submit the user information.
3. Send the information to the Gemini model.
4. Check the generated fitness plan.
5. Verify that the output matches the user's fitness goal.
6. Check the application for errors.

### 4. Expected Testing Outcome

The application should correctly accept user information, process the
request using Gemini, and display an appropriate fitness plan.

### 5. Bug Identification

Any errors found during testing will be recorded and corrected before
the final project demonstration.
